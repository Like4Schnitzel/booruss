# booruss
A universal booru RSS generator.

## Usage
1. Find/host a booruss instance: https://booruss.example.org
2. Take a booru link: https://safebooru.org/index.php?page=post&s=list&tags=yuri
3. Add this to your RSS reader: https://booruss.example.org/https://safebooru.org/index.php?page=post&s=list&tags=yuri
The feed is located at https://booruss.example.org/[url]/rss.xml

Note: This is in early development and has so far only been tested with safebooru posts. More coming soon.
